# IOS XR Show Commands Cheatsheet

## Interface Commands
- `show interfaces` - Display all interface status and statistics
- `show ip interface brief` - Quick summary of IP interface status
- `show ipv6 interface brief` - Quick summary of IPv6 interface status
- `show interfaces description` - Show interface descriptions

## Routing Commands
- `show route` - Display routing table
- `show route summary` - Display routing table summary
- `show bgp summary` - BGP neighbor summary
- `show bgp ipv4 unicast` - BGP IPv4 unicast routes
- `show ospf neighbor` - OSPF neighbor information
- `show isis neighbors` - IS-IS neighbor information

## System Commands
- `show version` - System version and uptime
- `show inventory` - Hardware inventory
- `show platform` - Platform information
- `show processes cpu` - CPU utilization
- `show memory summary` - Memory usage summary
- `show install active summary` - Active software packages

## Configuration Commands
- `show running-config` - Current running configuration
- `show configuration commit list` - List of configuration commits
- `show configuration rollback changes` - Show rollback changes

## Troubleshooting Commands
- `show logging` - System logs
- `show tech-support` - Comprehensive system information
- `show controllers` - Controller status
- `show alarms` - Active alarms
